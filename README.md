# KYRO

**Everything. Connected.**

KYRO is a connected digital ecosystem with three core modules:
- **Social** — profiles, community and messaging
- **Market** — products and marketplace
- **Events** — events and meetups

## Stack
- Next.js App Router + TypeScript
- Supabase (Auth, PostgreSQL, Storage)
- Vercel

## Development
```bash
npm install
npm run dev
```

The first milestone is a polished, responsive Dashboard MVP. Modules are kept independent so Social, Market and Events can grow without coupling their implementation.

## Environment
Configure the Supabase project URL and publishable key for the application. Keep all secret/service-role keys server-side only.
